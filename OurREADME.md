# README 
## Project overview
An intelligent next-generation shopping agent designed to understand evolving customer intent and provide context-aware product recommendations using the Amazon Reviews 2023 dataset.
Traditional product search systems rely heavily on rigid filters and isolated search queries. Our solution introduces a conversational shopping agent capable of understanding user intent across multiple turns while dynamically adapting its retrieval strategy.

The system is designed around four core pillars:

1. **Core Architecture — Intent Routing & Hybrid Pipeline**
2. **Dialog Strategy — Multi-Turn Scenario Evolution**
3. **Self-Evolution — Dynamic Context Programming**
4. **Evaluation Matrix — Product & Efficiency Metrics**

✨ Key Features

- **Conversational Memory** — Retains relevant preferences and constraints across multiple user interactions.
- **Buying/Browsing Detection** — Determines the user's current level of purchasing intent.
- **Dynamic User Profile** — Builds and updates user preferences throughout the conversation.
- **Intent-Based Routing** — Routes queries through different processing strategies based on user intent.
- **Context-Aware Product Retrieval** — Uses accumulated conversation context to improve product search.
- **Product Evaluation** — Evaluates recommendation quality and system efficiency.
